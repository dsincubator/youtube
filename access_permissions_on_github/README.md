# Access permissions for a GitHub organization

This meetup is about access permissions for a GitHub organization.

**Objectives**

-   Are you the owner, member, or collaborator of a GitHub organization?
-   Do you have rights to admin, write, or read a GitHub repository?
-   As a member of a GitHub organization or team, what access level do you
    get by default to all repos?
-   What consequences are there to a mistake depending on your role or
    access level?
