# Docker Fundamentals

## Overview

Docker bundles an app plus system dependencies into a portable image that runs as a container ("FedEx a laptop" — ship the whole working computer, not fragile notes). The incubator introduces Docker as the successor to `renv` for system-level reproducibility, then drills into image/container lifecycle, volumes/users, and compose. Core sources are [source_qY5ForDjgGY](../../sources/source_qY5ForDjgGY_docker-getting-started-with-the-rocker-project.md) (first `rocker/r-base` + `rocker/rstudio` runs), [source_OieR0VDxSRk](../../sources/source_OieR0VDxSRk_docker-use-cases.md) (use vs author, `rocker/verse:4.1.1` dissected), [source_3_0gUMqKikw](../../sources/source_3_0gUMqKikw_docker-managing-images.md) (managing images, dangling `<none>`), [source_CvOVn2zwi3k](../../sources/source_CvOVn2zwi3k_docker-using-volumes-and-managing-users.md) (volumes/users), plus compose ([source_kgGCNGLyqdg](../../sources/source_kgGCNGLyqdg_docker-docker-compose-and-env-files.md)), container management ([source_RO-OdWXfpBc](../../sources/source_RO-OdWXfpBc_docker-managing-containers.md)), and cloud/terminal contexts ([source__pBqBfjTKI4](../../sources/source__pBqBfjTKI4_cloud-introduction-to-cloud-computing.md), [source_NF7HPKt55Yk](../../sources/source_NF7HPKt55Yk_cloud-use-cases.md), [source_PRKOMCCOlI0](../../sources/source_PRKOMCCOlI0_continuously-build-and-deploy-a-shiny-app-on-google-cloud-run.md), etc.).

This Playbook pairs with [Rocker Project](../docker/rocker-project.md) and [Docker Use Cases](../docker/docker-use-cases.md), and underpins [Google Cloud Run](../cloud/google-cloud-run.md) and [Cloud Computing Fundamentals](../cloud/cloud-fundamentals.md).

## Key Concepts

- **Image vs container**: image = template; container = running instance; `docker run` creates a new container — [source_qY5ForDjgGY](../../sources/source_qY5ForDjgGY_docker-getting-started-with-the-rocker-project.md).
- **First runs**: `docker run --rm -ti rocker/r-base` → R 4.1.1 (`1+2`→3) proves not host-bound; `docker run -d -p 8787:8787 -e PASSWORD=yourpassword rocker/rstudio` → `localhost:8787` (or `<droplet-ip>:8787`) login `rstudio`/`yourpassword` — [source_qY5ForDjgGY](../../sources/source_qY5ForDjgGY_docker-getting-started-with-the-rocker-project.md), [source__pBqBfjTKI4](../../sources/source__pBqBfjTKI4_cloud-introduction-to-cloud-computing.md).
- **Self-help**: `docker --help`, `docker run --help`, reference page; `[OPTIONS]` optional, `IMAGE` mandatory — [source_qY5ForDjgGY](../../sources/source_qY5ForDjgGY_docker-getting-started-with-the-rocker-project.md).
- **Managing images** ([source_3_0gUMqKikw](../../sources/source_3_0gUMqKikw_docker-managing-images.md)): `docker images` (`<none>` dangling), `docker images ubuntu` (repo filter), `docker rmi ubuntu:14.04`, `docker images -q | xargs docker rmi` (batch by SHA), `docker images --filter "dangling=true"` / `-f`, `docker image prune` / `docker container prune`, `docker container ls` vs `docker ps`.
- **Volumes & users** ([source_CvOVn2zwi3k](../../sources/source_CvOVn2zwi3k_docker-using-volumes-and-managing-users.md)): `-v $HOME:$HOME` mount + `--workdir $HOME` start, `:ro` read-only for safe "sledgehammer" experiments.
- **Compose** ([source_kgGCNGLyqdg](../../sources/source_kgGCNGLyqdg_docker-docker-compose-and-env-files.md)): `docker-compose.yaml` services (line 2 `services:` + indented), `image: microsoft/azure-cli` vs `build: context: .` + `Dockerfile`, `env_file`, `docker compose up`.
- **Isolation patterns**: `rocker/verse` vs plain `rstudio`, detached (`-d --name my_job`), `docker ps`/`logs`/`exec my_job ls`, `tmux` — [source_00i28kdk8cM](../../sources/source_00i28kdk8cM_ds-tmux.md), [source_NF7HPKt55Yk](../../sources/source_NF7HPKt55Yk_cloud-use-cases.md).
- **When to dockerize**: prototype locally raw, then move sketched script into container to capture exact system + R deps beyond `renv` — [source_qY5ForDjgGY](../../sources/source_qY5ForDjgGY_docker-getting-started-with-the-rocker-project.md).

## Example

```bash
docker --help
docker run --help

docker run --rm -ti rocker/r-base
docker run -d -p 8787:8787 -e PASSWORD=yourpassword rocker/rstudio
# browse localhost:8787, user rstudio / yourpassword

docker images
docker images --filter "dangling=true" -q | xargs docker rmi
docker image prune
docker container prune

docker run --rm -it -v $HOME:$HOME -w $HOME rocker/verse:4.1.1 bash
ls; cd ..; ls; cd $HOME
docker run --rm -it -v $HOME:$HOME:ro -w $HOME rocker/verse:4.1.1 bash

docker run -d --name my_job -p 8787:8787 -e PASSWORD=123 rocker/verse
docker ps; docker logs my_job; docker exec my_job ls -t /home/rstudio
```
