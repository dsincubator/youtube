# Docker Use Cases

## Overview

Docker use cases separate *using* images from *authoring* them: most analyst needs are solved by a published image, authoring is rare. [source_OieR0VDxSRk](../../sources/source_OieR0VDxSRk_docker-use-cases.md) is the anchor, walking through five patterns with `rocker/verse:4.1.1`. Companions add detail: [source_3_0gUMqKikw](../../sources/source_3_0gUMqKikw_docker-managing-images.md) (image hygiene), [source_CvOVn2zwi3k](../../sources/source_CvOVn2zwi3k_docker-using-volumes-and-managing-users.md) (volumes/users), [source_kgGCNGLyqdg](../../sources/source_kgGCNGLyqdg_docker-docker-compose-and-env-files.md) (compose/env), [source_qY5ForDjgGY](../../sources/source_qY5ForDjgGY_docker-getting-started-with-the-rocker-project.md) (first runs), plus cloud ([source_NF7HPKt55Yk](../../sources/source_NF7HPKt55Yk_cloud-use-cases.md), [source_JdFA31-vJUE](../../sources/source_JdFA31-vJUE_cloud-use-case-host-shiny-apps.md), [source__pBqBfjTKI4](../../sources/source__pBqBfjTKI4_cloud-introduction-to-cloud-computing.md), [source_PRKOMCCOlI0](../../sources/source_PRKOMCCOlI0_continuously-build-and-deploy-a-shiny-app-on-google-cloud-run.md)), terminal ([source_00i28kdk8cM](../../sources/source_00i28kdk8cM_ds-tmux.md), [source_2Lcba2K8j6M](../../sources/source_2Lcba2K8j6M_terminal-setup-and-navigate.md), [source_DVmvsZk-9F4](../../sources/source_DVmvsZk-9F4_terminal-modify-your-file-system.md) etc.), and reproducibility ([source_uDx9NkoBqv8](../../sources/source_uDx9NkoBqv8_data-science-on-a-chromebook.md) Chromebook).

See [Docker Fundamentals](../docker/docker-fundamentals.md) and [Rocker Project](../docker/rocker-project.md); deploy path continues in [Google Cloud Run](../cloud/google-cloud-run.md).

## Key Concepts

- **Bash on demand** ([source_OieR0VDxSRk](../../sources/source_OieR0VDxSRk_docker-use-cases.md)): `docker run --rm -it -v $HOME:$HOME -w $HOME rocker/verse:4.1.1 bash` gives Linux `bash` on Windows/macOS without host pollution; `ls`, `cd ..`, `cd $HOME`, `exit`/`Ctrl+d`, `Ctrl+l` clear.
- **R version switching** ([source_OieR0VDxSRk](../../sources/source_OieR0VDxSRk_docker-use-cases.md)): `... rocker/verse:4.1.1 R` → R 4.1.1 vs `...:4.0 R` → R 4.0 (pulls if not cached) for reproducing bugs without touching host.
- **Read-only isolation** ([source_OieR0VDxSRk](../../sources/source_OieR0VDxSRk_docker-use-cases.md)): `-v $HOME:$HOME:ro` mounts home read-only for "sledgehammer" experiments that cannot break host.
- **Avoid install pain**: postgres example — "never install postgres locally, always run it from docker" — [source_OieR0VDxSRk](../../sources/source_OieR0VDxSRk_docker-use-cases.md).
- **Sharing environments**: repo holds `docker-compose.yaml` (line 2 `services:` + services at 3/12/23); consumer `git clone <url>` → `cd <repo>` → `docker compose up`; `image: microsoft/azure-cli` (pull) vs `build: context: .` + `Dockerfile` (build fresh) — [source_OieR0VDxSRk](../../sources/source_OieR0VDxSRk_docker-use-cases.md), [source_kgGCNGLyqdg](../../sources/source_kgGCNGLyqdg_docker-docker-compose-and-env-files.md).
- **Windows compatibility** ([source_OieR0VDxSRk](../../sources/source_OieR0VDxSRk_docker-use-cases.md)): `$HOME` may be undefined; use Git Bash or WSL, or define `HOME` env.
- **Cloud hand-off**: same Rocker image runs locally on `localhost:8787` or on droplet at `<ip>:8787`; detached (`-d --name my_job`) + RStudio background jobs survive closed laptops — [source_NF7HPKt55Yk](../../sources/source_NF7HPKt55Yk_cloud-use-cases.md), [source__pBqBfjTKI4](../../sources/source__pBqBfjTKI4_cloud-introduction-to-cloud-computing.md).
- **Production deploy**: `rocker/shiny` base for Shiny apps on Cloud Run — see [Google Cloud Run](../cloud/google-cloud-run.md) and [source_PRKOMCCOlI0](../../sources/source_PRKOMCCOlI0_continuously-build-and-deploy-a-shiny-app-on-google-cloud-run.md).

## Example

```bash
docker run --rm -it -v $HOME:$HOME -w $HOME rocker/verse:4.1.1 bash
ls; cd ..; ls; cd $HOME; exit

docker run --rm -it -v $HOME:$HOME -w $HOME rocker/verse:4.1.1 R
# work, then q()

docker run --rm -it -v $HOME:$HOME:ro -w $HOME rocker/verse:4.1.1 bash

git clone https://github.com/<org>/<repo>.git
cd <repo>
docker compose up

docker run -d --name my_job -p 8787:8787 -e PASSWORD=123 rocker/verse
docker exec my_job ls -t /home/rstudio
```
