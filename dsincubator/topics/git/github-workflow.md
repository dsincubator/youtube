# GitHub Workflow

## Overview

GitHub collaboration in the incubator is taught as a daily fork-and-clone workflow centered on pull requests. The baseline remote setup compares *ours* (single shared remote) versus *fork of ours* (personal fork + upstream), with `git remote -v`, `git fetch`, `git push`, and `gh repo create` / `gh browse` / `gh pr create` via the GitHub CLI. RStudio integration is covered in two parts (Part 1: `usethis::use_git()` / `use_github()` / `use_github_action()`; Part 2: Git pane, branches, and PR helpers), with `usethis::pr_*` family (`pr_init`, `pr_push`, `pr_sync`, `pr_merge_main`) as the R-centric glue.

Pull requests are framed as social code review, not just code delivery. Sessions on productive conversations about code, code reviews in practice, and `reprex`/`gh` tooling show how to suggest changes directly on a PR, set expectations for open-source participation, and manage reviews with `git status` / `git diff` discipline. Bilingual coverage (English [source_fnfeYPPG9gM](../../sources/source_fnfeYPPG9gM_usethis-pr-sync-english.md), Spanish [source_xx5WNZgQEdY](../../sources/source_xx5WNZgQEdY_usethis-pr-synch-espanol.md), and the Spanish git-best-practice example [source_nSJT8NGhSTs](../../sources/source_nSJT8NGhSTs_ejemplo-de-mejores-practicas-de-git.md)) ensures the workflow is accessible across the team.

At scale, GitHub is also project management: issues, boards, `qqKhQdejUOM` project-management session, and access-permissions for the `2DegreesInvesting` organization. The 62 sources for this topic span from `gh` CLI demos to `gh pr` terminal workflows, remote comparisons, and end-to-end blog-post publishing via `zv5_OSb6lRo` GitHub Flow.

> **Bilingual note**: This topic includes Spanish-language sources; key concepts are shared in English with Spanish titles preserved in the Sources table.
