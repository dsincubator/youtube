# usethis Workflow

## Overview

`usethis` is the automation layer for R package and project setup. Rather than memorising file formats, you call `use_*()` helpers that write the correct files, git-add them, and prompt for the next step. [source_AFuVF0oWFMY](../../sources/source_AFuVF0oWFMY_creating-an-empty-r-package-up-to-the-best-standards.md) demonstrates nearly every helper in sequence while building `tiltPolish`, and [source_C27MVWqWSMs](../../sources/source_C27MVWqWSMs_r-packages-the-whole-game.md) shows the contributor-focused subset (`use_r()`, `use_mit_license()`, `use_devtools()`). The series also covers GitHub-specific helpers (`pr_*`, `use_github_action`, `use_github_links`) across Spanish and English meetups.

The workflow is deliberately sequential: package → license/Git → README/pkgdown → docs/tests → CI/versioning, with each `use_*()` committed separately so the history teaches the setup.

## Key Concepts

- **Package scaffolding**: `usethis::create_package("tiltPolish")` (already auto-loaded via `.Rprofile`), `usethis::use_rstudio()` adds `.Rproj`, `usethis::use_mit_license()` / `use_gpl3_license()` adds `LICENSE`, `usethis::use_git()` initialises the repo — [source_AFuVF0oWFMY](../../sources/source_AFuVF0oWFMY_creating-an-empty-r-package-up-to-the-best-standards.md).
- **File creators**: `usethis::use_r("summarize_range")` → `R/summarize_range.R`, `usethis::use_test("summarize_range")` → `tests/testthat/test-summarize_range.R`, `usethis::use_package_doc()` → `R/mypkg-package.R` for package-level imports, `usethis::use_tidy_description()` normalises `DESCRIPTION` — [source_AFuVF0oWFMY](../../sources/source_AFuVF0oWFMY_creating-an-empty-r-package-up-to-the-best-standards.md).
- **Documentation & site**: `usethis::use_readme_rmd()` scaffolds `README.Rmd` (goal text "polish til data"), `usethis::use_github_links()` adds GitHub URLs, `usethis::use_pkgdown()` adds `_pkgdown.yml` and the `pkgdown` GitHub Action — [source_AFuVF0oWFMY](../../sources/source_AFuVF0oWFMY_creating-an-empty-r-package-up-to-the-best-standards.md).
- **Testing and conduct**: `usethis::use_testthat()` (adds `tests/testthat.R`, configures edition 3, `Suggests: testthat`), `usethis::use_code_of_conduct(contact = "maurolepore@gmail.com")` — [source_AFuVF0oWFMY](../../sources/source_AFuVF0oWFMY_creating-an-empty-r-package-up-to-the-best-standards.md).
- **CI and versioning**: `usethis::use_github_action("check-standard")` → `.github/workflows/R-CMD-check.yaml` on branch `add-CI`; `fledge::bump_version()` / `finalize_version()` via `-m` conventional commits for `NEWS.md` — [source_AFuVF0oWFMY](../../sources/source_AFuVF0oWFMY_creating-an-empty-r-package-up-to-the-best-standards.md).
- **GitHub PR helpers**: `usethis::pr_init()`, `pr_push()`, `pr_pull()`, `pr_view()` and `gh pr create --fill` / `gh pr merge --squash --delete-branch` for the `Closes #1` lifecycle; see [GitHub Workflow](../git/github-workflow.md) and [Creating R Packages](../r-packages/creating-packages.md).
- **Setup reuse**: `usethis::use_blank_slate()`, `use_devtools()`, `use_usethis()` to replicate the helper environment across RStudio Cloud projects; Spanish coverage in [source_hs_Pzxny7XE](../../sources/source_hs_Pzxny7XE_evita-solicitudes-de-fusion-interdependientes.md).
