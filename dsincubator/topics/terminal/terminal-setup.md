# Terminal Setup and Navigation

## Overview

Terminal literacy is treated as the prerequisite for cloud, Docker, and Git efficiency. The series builds from "what is a terminal" to everyday file/permission commands, using the incubator's `ds.terminal` hands-on. Anchors include [source_yOJZHRGF3Bk](../../sources/source_yOJZHRGF3Bk_terminal-overview.md) (overview), [source_V2oSfukR4mw](../../sources/source_V2oSfukR4mw_terminal-start-a-terminal-and-navigate-your-files-system.md) / [source_2Lcba2K8j6M](../../sources/source_2Lcba2K8j6M_terminal-setup-and-navigate.md) (setup+nav), [source_DVmvsZk-9F4](../../sources/source_DVmvsZk-9F4_terminal-modify-your-file-system.md) (modify), [source_iYlKc0BTjBk](../../sources/source_iYlKc0BTjBk_terminal-find-things.md) (find), plus multi-user and admin variants ([source_jyBv5ITO718](../../sources/source_jyBv5ITO718_terminal-create-a-custom-command-as-a-user-in-a-multi-user-system.md), [source_NuXgJtl9QDw](../../sources/source_NuXgJtl9QDw_terminal-running-commands-as-administrator.md), [source_BYtt2cXW4qg](../../sources/source_BYtt2cXW4qg_ds-terminal-use-case-customize-and-reuse-your-home.md)).

Continue in [tmux](../terminal/tmux.md); powers [Docker Fundamentals](../docker/docker-fundamentals.md) and [Git Fundamentals](../git/git-fundamentals.md); host for [Cloud Computing Fundamentals](../cloud/cloud-fundamentals.md).

## Key Concepts

- **Shell vs terminal** ([source_yOJZHRGF3Bk](../../sources/source_yOJZHRGF3Bk_terminal-overview.md)): terminal = window, shell = program (`bash`/`zsh`); prompt `user@host:~$`, history via ↑, tab-completion.
- **Navigation** ([source_V2oSfukR4mw](../../sources/source_V2oSfukR4mw_terminal-start-a-terminal-and-navigate-your-files-system.md), [source_2Lcba2K8j6M](../../sources/source_2Lcba2K8j6M_terminal-setup-and-navigate.md)): `pwd`, `ls`/`ls -a`/`ls -lh`, `cd` / `cd ..` / `cd ~`, absolute vs relative paths, `whoami`, `echo $HOME`.
- **Modify filesystem** ([source_DVmvsZk-9F4](../../sources/source_DVmvsZk-9F4_terminal-modify-your-file-system.md)): `mkdir -p`, `touch`, `cp`/`cp -r`, `mv`, `rm`/`rm -r`, `cat`/`less`/`head`/`tail`.
- **Find & inspect** ([source_iYlKc0BTjBk](../../sources/source_iYlKc0BTjBk_terminal-find-things.md)): `find . -name "*.R"`, `grep -r "pattern"`, `which`, `man`/`--help`, `history` + `!n`.
- **Multi-user customization** ([source_jyBv5ITO718](../../sources/source_jyBv5ITO718_terminal-create-a-custom-command-as-a-user-in-a-multi-user-system.md), [source_BYtt2cXW4qg](../../sources/source_BYtt2cXW4qg_ds-terminal-use-case-customize-and-reuse-your-home.md)): `~/.bashrc` / `~/.zshrc`, `alias ll='ls -lh'`, `export PATH=$HOME/bin:$PATH`, custom `bin/my-cmd` with `chmod +x`, dotfiles repo.
- **Admin** ([source_NuXgJtl9QDw](../../sources/source_NuXgJtl9QDw_terminal-running-commands-as-administrator.md), [source_CvOVn2zwi3k](../../sources/source_CvOVn2zwi3k_docker-using-volumes-and-managing-users.md)): `sudo <cmd>` (password), `sudo chown -R $USER:$USER`, `chmod +x`; read-only bind mount `:ro` for safe experiments; see [tmux](../terminal/tmux.md) for session persistence.

## Example

```bash
pwd; whoami; ls -a; ls -lh
mkdir -p /tmp/demo && cd /tmp/demo
touch a.csv b.csv; ls; cat a.csv
find . -name "*.csv"; grep -r "header" .
alias ll='ls -lh'; echo 'export PATH=$HOME/bin:$PATH' >> ~/.bashrc
sudo chown -R rstudio:rstudio /home/rstudio
chmod +x ~/bin/my-script
```
