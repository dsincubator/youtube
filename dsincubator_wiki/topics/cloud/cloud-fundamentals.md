# Cloud Computing Fundamentals

## Overview

Cloud computing is renting computing resources as a service — resources owned/managed by the provider — instead of buying hardware that ages. [source__pBqBfjTKI4](../../sources/source__pBqBfjTKI4_cloud-introduction-to-cloud-computing.md) opens the series with stakeholder benefits (orgs save on idle hardware, researchers get on-demand without HR/shipping waits, devs get templates, interns get private data quickly) plus the caveat "cloud is someone else's computer" (sensitivity/trust, billing by hour). [source_NF7HPKt55Yk](../../sources/source_NF7HPKt55Yk_cloud-use-cases.md) demos scaling (DigitalOcean `Resize` after `Turn off`, $10 2 GB → $5 1 GB, $0.007/hr), isolation via Rocker, and detached long runs. [source_16Xn0ueeP-E](../../sources/source_16Xn0ueeP-E_azure-rstudio-server-and-pins.md) grounds Azure RStudio Server + `pins`, [source_JdFA31-vJUE](../../sources/source_JdFA31-vJUE_cloud-use-case-host-shiny-apps.md) hosts Shiny apps, [source_VRG95a4aBW4](../../sources/source_VRG95a4aBW4_cloud-more-ways-to-move-data.md) surveys move-data patterns, and [source_PRKOMCCOlI0](../../sources/source_PRKOMCCOlI0_continuously-build-and-deploy-a-shiny-app-on-google-cloud-run.md) anchors serverless via Cloud Run.

Links to [Docker Fundamentals](../docker/docker-fundamentals.md), [Rocker Project](../docker/rocker-project.md), [Google Cloud Run](../cloud/google-cloud-run.md), and [Data Movement and Storage](../cloud/data-movement.md).

## Key Concepts

- **Definition**: cloud = rented service, not owned hardware; examples Shiny web-apps, Dropbox storage, vanilla servers (server = computer that serves a client); provider handles installs/fixes — [source__pBqBfjTKI4](../../sources/source__pBqBfjTKI4_cloud-introduction-to-cloud-computing.md).
- **Naming**: DigitalOcean calls a server a **droplet**; others call it VM/instance — [source__pBqBfjTKI4](../../sources/source__pBqBfjTKI4_cloud-introduction-to-cloud-computing.md), [source_NF7HPKt55Yk](../../sources/source_NF7HPKt55Yk_cloud-use-cases.md).
- **Create droplet** ([source__pBqBfjTKI4](../../sources/source__pBqBfjTKI4_cloud-introduction-to-cloud-computing.md)): Project → Create Droplet → OS `Ubuntu` (Marketplace or vanilla) → $5/mo basic 25 GB → region → SSH keys vs password (`Happy Git with R`) → ugly name to remind to delete → Create (2 min).
- **Connect**: `ssh root@<ipv4>` (IPv4 is resource address), `yes` on first key, then `whoami`→`root`, `pwd`, `ls`/`ls -a`/`ls /`, `docker run hello-world` verifies Docker — [source__pBqBfjTKI4](../../sources/source__pBqBfjTKI4_cloud-introduction-to-cloud-computing.md).
- **Rocker on cloud**: same `docker run rocker/rstudio` (or `rocker/verse` to avoid missing `tidyverse`) at `<ip>:8787` vs local `localhost:8787`; RStudio background jobs survive disconnect — [source_NF7HPKt55Yk](../../sources/source_NF7HPKt55Yk_cloud-use-cases.md), [source_16Xn0ueeP-E](../../sources/source_16Xn0ueeP-E_azure-rstudio-server-and-pins.md).
- **Costs & security** ([source__pBqBfjTKI4](../../sources/source__pBqBfjTKI4_cloud-introduction-to-cloud-computing.md), [source_NF7HPKt55Yk](../../sources/source_NF7HPKt55Yk_cloud-use-cases.md)): billed by hour; $5 forgotten 2 years → $120 bill; use On/Off toggle; data sensitivity — security is provider's business but leak liability is yours.
- **Scaling** ([source_NF7HPKt55Yk](../../sources/source_NF7HPKt55Yk_cloud-use-cases.md)): DigitalOcean resize requires power off, then memory- vs disk-optimized presets (e.g., 16 GB → $80/mo).
- **Hosting Shiny** ([source_JdFA31-vJUE](../../sources/source_JdFA31-vJUE_cloud-use-case-host-shiny-apps.md), [source_PRKOMCCOlI0](../../sources/source_PRKOMCCOlI0_continuously-build-and-deploy-a-shiny-app-on-google-cloud-run.md)): Cloud Run scales to demand and shuts down idle — see [Google Cloud Run](../cloud/google-cloud-run.md).
- **Moving data** ([source_VRG95a4aBW4](../../sources/source_VRG95a4aBW4_cloud-more-ways-to-move-data.md), [source_mamqEBZpbtw](../../sources/source_mamqEBZpbtw_cloud-move-data-between-a-server-and-github-with-the-gh-cli.md), [source_yldd8trFbaQ](../../sources/source_yldd8trFbaQ_cloud-resize-data-storage-and-share-data-with-pins.md)): `gh CLI`, `pins` + Dropbox — see [Data Movement and Storage](../cloud/data-movement.md).

## Example

```bash
ssh root@<droplet-ipv4>
whoami; pwd; ls -a; ls /
docker run hello-world

docker run -d -p 8787:8787 -e PASSWORD=yourpassword rocker/rstudio
# browse http://<droplet-ip>:8787  rstudio / yourpassword

# DigitalOcean UI: Droplet → Turn off → Resize → choose 16 GB preset → Turn on
```
