# dsincubator Wiki Index

## Overview

The dsincubator Wiki is an OKF v0.2 knowledge bundle that distills 151 video transcripts into 44 interlinked topic pages across 13 categories. It transforms ephemeral meeting captions into a durable, searchable playbook for data-science collaboration at 2 Degrees Investing. This index is the bundle entry point — it lists every topic, explains how the bundle is organized, and links to the underlying sources so readers can verify any claim against the original video.

The bundle follows the OKF v0.2 actor convention (`agent:okf-wiki-builder/1.0` for LLM-synthesized pages, `process:yt-dlp` / `process:convert-transcripts` for raw and converted transcripts, `human:<reviewer>` for verified fields) and verification tiers (§5.3). All topic pages are currently `status: draft` (unverified, advisory) pending human review, which will add `verified: { by: human:<reviewer>, at: <date> }` and flip status to `stable`. Pipeline topics with `type: Attested Computation` include executable `runtime` and `computation_type` metadata.

Sources are preserved one-to-one in `dsincubator_wiki/sources/` (one markdown source per transcript, with frozen frontmatter copied byte-identical from the transcript for `tags`, `lang`, `usage_count`, `last_modified`, and `sources[]`). Topics synthesize 2–20 sources each; cross-links connect related topics and link back to verbatim source excerpts. The reserved filename `topics/index.md` is not used per §3.1 — this file (`topics/concepts-overview.md`) serves as the index.

> **Bilingual note**: This topic includes Spanish-language sources; key concepts are shared in English with Spanish titles preserved in the Sources table.
