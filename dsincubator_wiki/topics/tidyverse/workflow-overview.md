# Tidyverse Data Science Workflow

## Overview

This Playbook synthesizes the tidyverse's workflow view of data science: import → tidy → transform → visualize → model → communicate, looping through exploratory data analysis. [source_0-zQ69P6VsY](../../sources/source_0-zQ69P6VsY_tidy-eda-the-data-science-workflow-and-toolkit-an-overview.md) frames the toolkit (readr, tidyr, dplyr, ggplot2, purrr, stringr, forcats, lubridate) and the pipe `%>%`/`|>`, while the EDA sequence ([source_26hbyVb00xs](../../sources/source_26hbyVb00xs_eda-with-the-tidyverse-exploring-variation.md), [source_HJCUlCgEnqM](../../sources/source_HJCUlCgEnqM_eda-unusual-and-missing-values.md), [source_Hv6DzT6Z2yA](../../sources/source_Hv6DzT6Z2yA_tidy-eda-patterns-and-models.md), [source_WBmLuUV5BEE](../../sources/source_WBmLuUV5BEE_tidy-eda-covariation-between-one-categorical-variable-and-one-continuous-variable.md), [source_k8GykC4ZXW0](../../sources/source_k8GykC4ZXW0_tidy-eda-covariation-between-two-categorical-variables-and-between-two-continuous-variables.md)) walks the steps repeatedly with `diamonds`, `mpg`, and `nycflights13` datasets.

The incubator adds defensive and project-oriented overlays: [source_YlBnarQNRR8](../../sources/source_YlBnarQNRR8_tidy-eda-defensive-workflow.md), [source_cKAXDJq5ZdA](../../sources/source_cKAXDJq5ZdA_wtf-holistic-workflow-part-1.md), [source_TEUbVjhooIg](../../sources/source_TEUbVjhooIg_project-oriented-workflow.md), and communication via R Markdown ([source_wJnI0F_A-bU](../../sources/source_wJnI0F_A-bU_creating-reproducible-examples.md)).

## Key Concepts

- **The workflow diagram**: import (readr, readxl, haven) → tidy (tidyr) → transform (dplyr) → visualize (ggplot2) → model (modelr) → communicate (rmarkdown), wrapped by programming (purrr) — [source_0-zQ69P6VsY](../../sources/source_0-zQ69P6VsY_tidy-eda-the-data-science-workflow-and-toolkit-an-overview.md).
- **Tidy data**: one observation per row, one variable per column, one value per cell; `pivot_longer`/`gather` + `separate` + `unite` — [source_VA3qaeTKTYk](../../sources/source_VA3qaeTKTYk_tidying-data.md) — see [Tidy Data](../tidyverse/tidy-data.md).
- **Transformation verbs**: `select`, `filter`, `mutate`, `arrange`, `summarize` + `group_by`, `count`, pipe — [source_3rf1W9ceKhU](../../sources/source_3rf1W9ceKhU_failing-fast-in-dplyr-chains.md) — see [dplyr Verbs](../tidyverse/dplyr-verbs.md).
- **Visualization**: grammar of graphics layers (data, aes, geom, facet, scale, coord, theme) with `ggplot2` — [source_26hbyVb00xs](../../sources/source_26hbyVb00xs_eda-with-the-tidyverse-exploring-variation.md) — see [ggplot2 Fundamentals](../tidyverse/ggplot2-fundamentals.md).
- **EDA loop**: variation (`geom_histogram`/`geom_bar`) → covariation (categorical×categorical, categorical×continuous, continuous×continuous) → unusual/missing → patterns and models — [source_WBmLuUV5BEE](../../sources/source_WBmLuUV5BEE_tidy-eda-covariation-between-one-categorical-variable-and-one-continuous-variable.md), [source_k8GykC4ZXW0](../../sources/source_k8GykC4ZXW0_tidy-eda-covariation-between-two-categorical-variables-and-between-two-continuous-variables.md), [source_Hv6DzT6Z2yA](../../sources/source_Hv6DzT6Z2yA_tidy-eda-patterns-and-models.md).
- **Missing values**: identify via `filter(is.na)`, `ggplot(aes(y=x)) + geom_miss` patterns, handle with `drop_na`, `replace_na` — [source_HJCUlCgEnqM](../../sources/source_HJCUlCgEnqM_eda-unusual-and-missing-values.md) and [source_KxybJ_zVJUA](../../sources/source_KxybJ_zVJUA_eda-with-the-tidyverse-typical-unusual-and-missing-values.md) — see [EDA: Missing Values](../tidyverse/eda-missing-values.md).
- **Defensive + holistic + project-oriented**: `here::here()`, `fs`, `use_blank_slate`, naming conventions (`xW05GsfhuiY`), and iterative polish vs production — see [Project-Oriented Workflow](../workflow/project-oriented-workflow.md) and [Reproducible Workflows](../pipelines/reproducible-workflows.md).
- **Communication**: R Markdown/Quarto mixing prose + code; see [R Markdown Communication](../tidyverse/rmarkdown-communication.md) and [source_erv1yJaNID8](../../sources/source_erv1yJaNID8_reprex-overview.md).
